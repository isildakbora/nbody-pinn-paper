# Time-Marching PINN for the Planar Three-Body Problem

Interactive companion page for the article on physics-informed neural networks for the planar Newtonian three-body problem.

Live page: served from GitHub Pages at this repository's URL.

- `index.html`: interactive paper (self-contained, data embedded)
- `paper.pdf`: the article

The network is trained only on the equations of motion. Reference solutions come from DOP853 (SciPy).
